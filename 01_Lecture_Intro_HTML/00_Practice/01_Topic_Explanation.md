## Topic: What is Web Development?

**What is it?**
Web development is the process of creating websites and web applications that run inside a browser.

**Why do we need it?**
Every online platform — social media, shopping sites, banking apps — runs on web technologies.

**How it works (basic idea)**
Users access websites through browsers. The browser loads files (HTML, CSS, JS) from a server and displays the interface.

**Real-world use case**
Amazon, YouTube, LinkedIn are all results of web development.

**Key Points to Remember**

* Web development builds websites and apps
* Runs inside browsers
* Uses HTML, CSS, JavaScript

---

## Topic: Frontend vs Backend

**What is it?**
Frontend is what users see. Backend is the server-side logic and database.

**Why do we need it?**
Frontend handles UI, backend handles data and logic.

**How it works**
Frontend sends requests, backend processes and sends responses.

**Real-world use case**
Login form (frontend) → server checks password (backend).

**Key Points to Remember**

* Frontend = UI
* Backend = logic + database
* Both communicate via requests

## Topic: Client–Server Model

**What is it?**
A system where client (browser) requests services from a server.

**Why do we need it?**
Centralized data and logic management.

**How it works**
Client sends HTTP request → server responds with data.

**Real-world use case**
Opening Instagram feed loads data from servers.

**Key Points**

* Client asks, server responds
* Communication over internet
* Uses HTTP/HTTPS

## Topic: Role of HTML, CSS, JavaScript

**What is it?**
Three core technologies of the web.

**Why do we need it?**
To structure, design, and add logic to web pages.

**How it works**
HTML = structure, CSS = styling, JS = interactivity.

**Real-world use case**
Button click showing popup (JS), styled with CSS, placed with HTML.

**Key Points**

* HTML = skeleton
* CSS = design
* JS = brain

## Topic: What are Browsers & Rendering

**What is it?**
Browsers are software that interpret and display websites.

**Why do we need it?**
They convert code into visual pages.

**How it works**
Browser reads HTML → builds DOM → applies CSS → runs JS → displays page.

**Real-world use case**
Chrome loading a website.

**Key Points**

* Browser renders code
* Uses rendering engine
* DevTools help inspect pages

## Topic: HTML Basics (Tags & Attributes)

**What is it?**
HTML uses tags to define elements and attributes to give extra information.

**Why do we need it?**
To build structured web pages.

**How it works**
Tags define elements, attributes modify behavior.

**Real-world use case**
Image source via `src`, link destination via `href`.

**Key Points**

* Tags form structure
* Attributes provide details
* Some tags are block, some inline

---

## Topic: Semantic vs Generic Tags

**What is it?**
Semantic tags describe meaning; generic tags are just containers.

**Why do we need it?**
Improves SEO and accessibility.

**How it works**
`<header>`, `<footer>` describe purpose; `<div>` does not.

**Real-world use case**
Search engines understanding page layout.

**Key Points**

* Semantic = meaningful
* Generic = layout only
* Use semantic whenever possible
