## Practice Questions (With Answers)

**Q1. Why do we need programming languages?**
**Answer:** To give structured instructions to computers in human-readable form.

**Q2. Is JavaScript compiled or interpreted?**
**Answer:** Interpreted.

**Q3. What does dynamic typing mean?**
**Answer:** Variable types can change during runtime.

**Q4. Why is JavaScript called single-threaded?**
**Answer:** It executes one main task at a time.

**Q5. Difference between var and let?**
**Answer:** var is function-scoped; let is block-scoped.

**Q6. Can const variables change?**
**Answer:** No reassignment allowed.

**Q7. What is ECMAScript?**
**Answer:** Standard specification for JavaScript.

**Q8. Name 3 primitive data types.**
**Answer:** Number, String, Boolean.

**Q9. typeof null returns?**
**Answer:** "object" (legacy bug).

**Q10. What is a Symbol used for?**
**Answer:** Unique identifiers for object properties.

**Q11. What is implicit type conversion?**
**Answer:** Automatic conversion during operations.

**Q12. Result of "5" - 2?**
**Answer:** 3

**Q13. Difference between == and ===?**
**Answer:** == allows coercion; === checks type too.

**Q14. Does slice modify original array?**
**Answer:** No.

**Q15. Does splice modify original array?**
**Answer:** Yes.
