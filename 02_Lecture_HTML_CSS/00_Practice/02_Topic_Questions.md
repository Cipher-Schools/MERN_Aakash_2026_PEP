## Practice Questions (With Answers)

**Q1. Why are semantic tags better than using only div tags?**
**Answer:** Semantic tags give meaning to content, improving SEO, accessibility, and readability of code.

**Q2. What happens when a form is submitted?**
**Answer:** The browser collects input data and sends it to the server defined in the form action.

**Q3. Difference between radio and checkbox inputs?**
**Answer:** Radio allows only one selection in a group; checkbox allows multiple.

**Q4. What is the purpose of a label tag?**
**Answer:** It describes an input and improves accessibility by linking text to input.

**Q5. What is the use of the `multiple` attribute in select?**
**Answer:** Allows users to select more than one option.

**Q6. What are `<tr>`, `<th>`, `<td>`?**
**Answer:** Table row, table header cell, table data cell.

**Q7. What does `font-weight: bold;` do?**
**Answer:** Makes text thicker.

**Q8. Difference between class and ID selectors?**
**Answer:** Class can be reused; ID must be unique.

**Q9. What is inline CSS?**
**Answer:** CSS written directly in the style attribute of an element.

**Q10. What is the box model made of?**
**Answer:** Content, padding, border, margin.

**Q11. What does `display: none;` do?**
**Answer:** Hides the element completely from layout.

**Q12. What does `justify-content: center;` do in flexbox?**
**Answer:** Centers items horizontally.

**Q13. What does `align-items: center;` do?**
**Answer:** Centers items vertically in flex container.

**Q14. What does `flex-grow: 1;` mean?**
**Answer:** Item can grow to fill available space.

**Q15. Why is external CSS preferred in large projects?**
**Answer:** Better organization, reusability, and performance.
