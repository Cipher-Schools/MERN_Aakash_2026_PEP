## Practice Questions (With Answers)

**Q1. What does overflow: hidden do?**
**Answer:** It clips content that exceeds container size.

**Q2. Why are media queries important?**
**Answer:** They make websites responsive.

**Q3. Difference between flexbox and grid?**
**Answer:** Flexbox is 1D, Grid is 2D.

**Q4. What does flex-wrap do?**
**Answer:** Allows items to move to next line.

**Q5. What does justify-content control?**
**Answer:** Horizontal alignment in flexbox.

**Q6. What does align-items control?**
**Answer:** Vertical alignment in flexbox.

**Q7. What is grid-template-columns?**
**Answer:** Defines column structure.

**Q8. What is minmax() used for?**
**Answer:** Sets min and max size for grid tracks.

**Q9. Difference between relative and absolute positioning?**
**Answer:** Relative moves from itself; absolute moves relative to positioned ancestor.

**Q10. What does position: fixed do?**
**Answer:** Fixes element relative to viewport.

**Q11. What is sticky positioning used for?**
**Answer:** Elements that stick while scrolling.

**Q12. Difference between var and let?**
**Answer:** var is function scoped; let is block scoped.

**Q13. Can const variables change?**
**Answer:** No, cannot be reassigned.

**Q14. How do you run a JS file using Node?**
**Answer:** `node filename.js`

**Q15. What does order property do in flexbox?**
**Answer:** Changes item order visually.
